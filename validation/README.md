# 第2評価者による検証

認知ギャップの判定器（`gap_classifier.py` の primary）が正しいかを、人の目で確かめるための手順とコード。
結果（シート、評価、集計）はこのリポジトリに含めない。未公開の研究成果のため、出力は gitignore の外に置かない。

## 手順

1. 検証用シートを作る（層ごとの無作為抽出。象限は評価者に伏せる）。

   ```
   python validation/make_validation_sheet.py --db PATH/integrated_db_japan.json --out DIR [--seed 2026]
   ```

   出力: `validation_sheet.xlsx`（評価者に渡す）、`answer_key.csv`（判定器の結果。評価が終わるまで見せない）、`sampling_plan.json`。

2. 評価者ごとに `validation_sheet.xlsx` を複製して渡す。評価者は、題名と抄録だけを読み、次の2つを判定する（独立に。他の評価者の回答や判定器の結果は見ない）。
   - 処方名の言及: 有 / 無 / 不明
   - 漢方診断の記載: 有 / 背景のみ / 無 / 不明（証・漢方の病態・診察所見が、対象の説明や処方選択の根拠として書かれているか）

3. 返送されたシートを集計する。

   ```
   python validation/analyze_validation.py --key DIR/answer_key.csv --rater 評価者1=sheet1.xlsx --rater 評価者2=sheet2.xlsx --out report.md
   ```

   出力: 評価者間の一致（Cohen の κ）、判定器の PPV・NPV・感度・特異度（層の母集団で重み付け）、補正後のギャップ（層内の再抽出による95%信頼区間）。
   漢方診断の定義は、厳密（『有』のみ）と寛容（『有』『背景のみ』）の両方を出す。

## 設計

- 層: セット（日本語の雑誌、PubMed）× 象限（Q1〜Q4）の8層。標本は Q1 と Q3 が50〜60件、Q2 と Q4 が30件（PubMed の Q1 は母集団が少ないので全数）。
- Q2 と Q4 は、判定器が処方名を取りこぼしていないかを確かめるために抜く。PubMed の Q4 は母集団が大きいので、取りこぼしの割合の信頼区間は広くなる。必要なら件数を増やす。
- シートは A・B の2つの束に分かれている。各層から半分ずつ入っているので、A だけ先に終えても、補正後のギャップを（精度は落ちるが）推定できる。
- 補正後のギャップ = 1 − （処方名が有かつ診断が有）/（処方名が有）。『不明』は欠測として除く。
- 評価者2人は独立に判定し、κ で一致を確かめる。辞書の作成者が評価者に入る場合は、辞書の作成者ではない評価者の判定を「独立した検証」とする。
